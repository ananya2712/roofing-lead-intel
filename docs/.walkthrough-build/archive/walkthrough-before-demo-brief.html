1. Project overview and requirements

Problem. Sales representatives of a roofing-materials distributor research contractors by hand before account planning. Users. Distributor representatives (one shared workspace, no login). Workflows. Review prospects → open a prospect → save as lead → work the call lists → change status → check the Overview.

6. Deterministic rules

RuleWhereExact behavior
Distancescoring._geographic≤10 mi → 35; ≤25 → 22; ≤50 → 10; unknown → 0 (marked unknown)
Certification tierscoring._certificationTop (President's Club, Master Elite, Chairman's Circle, PlatinumElite) → 20; Certified (Certified, GoldElite, CoatingsPro) → 12; none → 0. Substring match, top tier checked first.
Roof systemsscoring._roof_systemsResidential listing → 10; commercial with technologies → 10; else 0
Specialtyscoring._specialtyAny value containing fortified, metal, solar or coating → 5
Readinessscoring._readinessPhone 10; website 10; street+city+state 5; retrieved ≤30 days before the effective time 5
Tierscoring.tier_forHigh ≥70; Medium 45–69; Low <45
Prospect orderqueries._orderscore desc, distance asc (nulls last), name, id
Phone normalizationimporter.phone_digitsDigits only; drop a leading 1 from 11 digits; keep only 10 digits, else None
Listing identityuq_prospect_listing(directory, gaf_source_id) unique; import upserts on it
One lead per companyuq_leads_company_keyPartial unique index on leads.company_key where not null
Follow-up dueservices.is_follow_up_duestatus = contacted and now − status_changed_at ≥ 14 days
Lead orderservices.LEAD_SORTSpriority: score desc, name, id; recently_saved: saved_at desc, id; oldest_status_change: status_changed_at asc, id

Worked example: prospect 20, Redline Enterprises LLC

Inputs: residential, 38.0 mi, phone listed, no website, full address, distinctions FORTIFIED Roof™, GAF Master Elite®, President's Club; retrieved the same day.

distance 10 + certification 20 + roof systems 10 + specialty 5 + phone 10 + website 0 + address 5 + freshness 5 = 65 → Medium

This matches the API response for prospect 20. Repeatability: the score depends only on the prospect row and the effective time. Freshness points change only when flask rescore runs after 30 days. Saving a lead or changing status never changes the score. Search relevance vs. priority: GAF's own result order is not stored or used; priority is this score only.

7. Key design decisions

DecisionWhy it fits the MVPAlternative and trade-off
One-time browser snapshot (D1)gaf.com returns HTTP 403 to plain HTTP clients; a browser shows the data.Headless scraping or GAF's search key: can break and works against GAF's block.
Three tables by field group (D4)Source data, derived scores and representative work change for different reasons.One wide table: simpler, but every rescore or import touches representative data.
Constraints for duplicates (D8)Correct under parallel requests and repeated imports.Application-only checks: race conditions.
Directory filter in SQL (D19)Counts and lists agree for the chosen directory.Filter after loading: wasteful and easy to make inconsistent.
Leads filtered in Python (inferred)Small saved set and time-based rules; simple code.SQL filters: needed when saved leads grow.
Same-origin proxy (D15)No CORS; one URL for users.Direct calls with CORS headers.
No Alembic (D5)Less setup for the MVP, as the user asked.Alembic: needed before the schema changes with real data.

Recorded rationale is in docs/DECISION_LOG.md. Rows marked "inferred" are the writer's reading of the code.

9. Verification and limitations

Automated tests: none written or run (the user decides when; plan in docs/TEST_PLAN.md).

Manual checks on 2026-11-05 (details in docs/BUILD_PROGRESS.md): complete imports (176/176, 233/233); re-import adds 0 rows; save 201 → repeat 200 → other listing 409; 404 and 422 responses; empty query values accepted; the 14-day follow-up boundary; a repeated status keeps its timestamp; directory filter counts; restart persistence; tsc --noEmit passes.

Limitations: snapshot data from one day; no login; no status history; phone-based company matching can miss or merge companies; 209 of 233 commercial listings have no website on GAF, so they lose 10 points; local Git metadata is not present in the folder.
